# LectureBridge — はじめてのセットアップ

**Language:** [English](../getting-started.md) | [Tiếng Việt](getting-started.vi.md) | [简体中文](getting-started.zh-Hans.md) | [繁體中文](getting-started.zh-Hant.md) | [日本語](getting-started.ja.md) | [한국어](getting-started.ko.md)

LectureBridge はブラウザーにリアルタイム字幕を表示し、必要に応じてベトナム語に翻訳します。このガイドでは、新しい Windows または Ubuntu のパソコンへのインストールから、短いセッションの試用までを説明します。Git、Python、CUDA Toolkit を自分でインストールする必要はありません。

**ガイドの言語、音声の言語、翻訳先の言語は別の設定です。** 日本語のガイドを開いてもアプリの設定は変わりません。音声認識は英語、中国語（標準中国語）、日本語、韓国語に対応し、翻訳先はベトナム語です。ベトナム語は現在、音声の入力言語として選択できません。アプリの画面はベトナム語、インストーラーのメッセージは英語です。

## 1. 準備するもの

- Windows 10/11 x86-64、または Ubuntu 22.04/24.04 x86-64。
- 4 GB 以上の RAM と、インストール先に 20 GB 以上の空き容量。
- インストールとモデルのダウンロードに使うインターネット接続。ライブラリーのダウンロードは数 GB になる場合があります。モデルのキャッシュ先にも 2 GB 以上、翻訳を使う場合はさらに約 2.5 GB の空き容量が必要です。
- マイクと、対象の音声を収録する許可。NVIDIA GPU は必須ではありませんが、CPU では処理が遅くなる場合があります。

## 2. ダウンロードして展開する

[Releases](https://github.com/Nguyen-Le-Tuan/lecturebridge/releases) の **Assets** を開きます。Windows は `*-windows-x64.zip`、Ubuntu は `*-ubuntu-x64.tar.gz` を選んでください。GitHub が自動生成する **Source code** ではなく、これらのインストール用アーカイブを使います。直接受け取ったファイルも使用できます。非公開リポジトリからダウンロードするにはアクセス権が必要です。

アーカイブ全体を、書き込み可能で今後も使うフォルダーに展開します。その中の `Install.cmd` と `Install.sh` があるフォルダーを開いてください。圧縮ファイルの閲覧画面から直接実行しないでください。

## 3. インストールして起動する

### Windows

1. `Install.cmd` をダブルクリックします。
2. 音声で実際に話される言語を選び、**Setup complete** と表示されるまで待ちます。
3. Microsoft Visual C++ のインストール許可を求められたら承認します。再起動が必要と表示された場合は、自分で Windows を再起動し、Install をもう一度実行してください。
4. `Start.cmd` をダブルクリックします。

### Ubuntu

展開したフォルダーでターミナルを開きます。最初のコマンドを実行し、**Setup complete** を確認してから次を実行します。

```bash
bash Install.sh
bash Start.sh
```

表示に従って音声の言語を選びます。不足しているシステムパッケージのインストールには `sudo` のパスワードが必要な場合があります。入力中は文字が表示されませんが、そのまま入力して Enter を押してください。

Install はライブラリーをダウンロードし、小さな初期モデルを選びます。インストール中はハードウェアの確認だけを行い、モデルの推論や GPU ドライバーの変更は行いません。条件を満たす GPU で初めて起動すると、Start は時間とリソースを制限した `tiny` のチェックを実行します。失敗した場合、そのセッションは CPU で起動します。ブラウザーで [http://127.0.0.1:8000](http://127.0.0.1:8000) が開きます。使用中はターミナルを開いたままにしてください。

## 4. 短いセッションで試す

ブラウザーのマイク使用を許可します。最初は録音保存と翻訳をオフにして、15–30 秒ほど話してください。**Bắt đầu nghe** は開始、**Dừng phiên** はセッション停止です。先にアプリ内で停止し、その後ターミナルで Ctrl+C を押すとサーバーを終了できます。

翻訳は別のセッションで試します。**Tiếng Việt**（ベトナム語）または **Song ngữ**（二言語表示）を選び、モデルのダウンロードを承認してください。翻訳は CPU 上で動作し、新しく確定した字幕だけを処理します。数十秒遅れる場合があります。

音声とテキストを残すには、開始前に **Lưu bản ghi**（録音を保存）をオンにします。終了後、**Thư viện**（ライブラリー）で再生や TXT/JSON/WAV の書き出しができます。音声は WAV、確定した字幕と取得済みの翻訳は `library.sqlite3` に保存されます。独立したテキストファイルが必要な場合は書き出してください。保存先は Windows が `%LOCALAPPDATA%\LectureBridge`、Ubuntu が `${XDG_DATA_HOME:-~/.local/share}/lecturebridge` です。ブラウザーから書き出すファイルは、ブラウザーのダウンロード設定に従います。

## 5. 音声の言語を選ぶ

| 音声の言語 | コード |
| --- | --- |
| 英語 | `en` |
| 中国語（標準中国語） | `zh` |
| 標準中国語、翻訳元を繁体字中国語として扱う設定 | `zh-Hant` |
| 日本語 | `ja` |
| 韓国語 | `ko` |

変更前にサーバーを終了します。日本語に切り替える例です。

```powershell
.\Start.cmd --language ja
```

```bash
bash Start.sh --language ja
```

OS に合うコマンドを一つ実行してください。Start は選択を記憶します。`zh-Hant` は `zh` と同じ音声認識器を使うため、字幕が必ず繁体字になるわけではありません。中国語・日本語・韓国語には `tiny`、`base`、`small` などの多言語モデルが必要です。`.en` モデルと `distil-large-v3.5` は英語専用です。

## 6. うまく動かないとき

- インストール失敗：`.lecturebridge/setup.log` を確認し、表示された問題を解決して Install を再実行します。完了するまで Start はアプリを起動しません。
- ブラウザーが開かない：サーバーの起動を待ち、`http://127.0.0.1:8000` を自分で開きます。
- ポート 8000 が使用中：以前のサーバーを終了します。
- CPU のみで使いたい：サーバーを終了し、インストール先で OS に合う以下のコマンドを実行します。例は日本語音声用です。

```powershell
.\Install.cmd -Profile cpu -Language ja
```

```bash
bash Install.sh --profile cpu --language ja
```

最初のセッションは短くしてください。**リアルタイムサーバーには、温度による自動停止機能がありません。** パソコンが熱くなったり反応が悪くなったりしたら停止してください。制限付き GPU チェックは試験時間を抑えますが、すべてのドライバーやシステム障害を防げるわけではありません。

同じパソコン上での使用に Tailscale は不要です。スマートフォンや iPad を接続する場合は、下記の Tailscale HTTPS ガイドを参照してください。更新版は新しいフォルダーにインストールし、`.venv` を別のパソコンや OS にコピーしないでください。録音はユーザーデータの保存先に残ります。
