# Windows testing

Use [Windows setup](setup-windows.md) to install the application and
[Testing LectureBridge](testing.md) for short caption, recording, translation,
and optional GPU checks. The [report template](acceptance-report-template.md)
lists the information to include with a result.

This page preserves links from earlier test reports. Current instructions use
release archives or `main`, rather than the old feature branch.
